## 三、参数（光有提示词出不来可用素材）

**输入图是 192×208，这是最大的坑**：图生图的输出尺寸通常被输入尺寸绑死，直接出图仍是 192×208 的小图。

- **尺寸**：设 768×832（保持 192:208 ≈ 0.923 的原始比例，别改成正方形，否则角色会被拉变形）
- **重绘强度（denoise / strength）**：
  - `0.40–0.50` 保结构最多，只提清晰度和细节 —— 先从这档试
  - `0.55–0.65` 推荐档，保留角色特征同时重绘质感
  - `0.70–0.85` 只借配色和气氛，容易跑形（跑形了就往回调）
- **CFG Scale**：SD 系 6–8；Niji/MJ 系 5–6
- **采样器**：DPM++ 2M Karras 或 Euler a，步数 28–36
- **锁定一致性**：固定 checkpoint + 固定 seed + 提示词顺序不要变，只微调细节。换工具角色必然漂。
- **二次放大（必做）**：出图后走 hires.fix 或 4x 放大模型，最终**高 ≥ 1200px**。我要的立绘槽位是 440×702，素材高 ≥ 800px 才不掉细节。
- **更好的替代方案**：用 ControlNet（`lineart` 或 `softedge`）+ 高分辨率直接生成，结构锁得住、分辨率不受输入限制，通常比纯图生图效果好。

**平台语法速查**

| 平台 | 图生图与权重写法 |
|---|---|
| NijiJourney / Midjourney | 传参考图后 `--iw 1.5`（参考图权重）、`--ar 9:10 --niji 6 --style raw` |
| NovelAI | 有独立的 img2img 强度滑杆；权重用 `{{tag}}` / `[[tag]]` |
| WebUI / ComfyUI / Liblib | 标准 SD 语法 `(tag:1.2)` |
| 即梦 / 通义万相 / 可灵 | 中文提示词直接可用，用"参考图/图生图"功能；可灵的人物一致性较好 |

**透明背景**：能从生成器直出 alpha 的（NovelAI 部分模型支持 `transparent background`）最好；出不来就用纯白底，我用 `tools/extract-art.js` 抠 —— 边缘连通法，实测能在 192×208 的原帧上清掉 25160 个背景像素同时保住角色身上的白靴子。

## 四、出图后自检清单

1. **全身完整**：头顶到脚底都在画面内，没有被裁
2. **正面、直立**，不做动态姿势（立绘要能直接叠到工作区右下角）
3. **无地面投影**：有的话抠底会留一圈灰边
4. **背景干净**：纯白或均匀单色；有渐变也能用但要调参；带场景元素就废了
5. **线条闭合**：线稿断线会让光效边缘发毛
6. **配色对得上**：拿上面那张色值表比对，偏色太多的话主题 token 要重新配
